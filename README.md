PLUMBER QUEST ONLINE — FINAL BUILD
=================================

CÁCH CHẠY LOCAL
---------------

1. Cài Node.js
2. Mở terminal trong thư mục project
3. Chạy:

npm install
npm start

4. Mở trình duyệt:

http://localhost:3000
